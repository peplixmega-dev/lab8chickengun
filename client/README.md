# Верити — агромаркет мега лучший

Кистанов Даниил мега. Это клиентская часть моей 8-й лабы, продолжение 7-й.

Тут всё по-старому: каталог с товарами «джяйй», «дешка», «кайф» и «мега», корзина, доставка «Не Астана - Долговато» и оптовая заявка. Плюс появилась авторизация и работа с API из лабораторной №8.

## Запуск

```bash
npm install
npm run dev
```

Для загрузки каталога и заявок нужен запущенный сервер из `../server`. В базе PostgreSQL товары берутся из `server/data/db.json` при запуске `npm run seed` (осторожно: скрипт пересоздаёт таблицы).
